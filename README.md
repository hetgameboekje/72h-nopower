# 72 uur zonder stroom

Dit project onderzoekt hoe inwoners tijdens een langdurige stroom- en netwerkuitval (tot 72 uur) toch betrouwbare crisisinformatie kunnen ontvangen.

De kern is een energiezuinig informatiepunt in de wijk met onder andere een e-ink scherm, lokale noodstroom en draadloze verbinding. Via één beheeromgeving kunnen bevoegde beheerders berichten op afstand publiceren, aanpassen en intrekken.

De oplossing richt zich op duidelijke en toegankelijke communicatie voor diverse doelgroepen, met nadruk op robuustheid, eenvoud en inzetbaarheid binnen enkele uren.
